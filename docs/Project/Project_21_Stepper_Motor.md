# Проект 21: Шаговый двигатель


![](../media/25065d20a3e6349227eb7f4dd5a7bfd2.png)

#### Описание

Шаговый двигатель может преобразовывать электрические сигналы в точное угловое перемещение для реализации точного позиционирования. 5V шаговый двигатель требует напряжение всего 5 вольт, поэтому он отличается небольшими размерами, легким весом и простотой эксплуатации, и широко используется во многих электронных устройствах и автоматизированных системах.

В этом проекте мы точно управляем шаговым двигателем с помощью платы разработки UNO R3 (ch340). Благодаря этому проекту вы поймете **принцип работы** шагового двигателя, научитесь управлять шаговым двигателем и регулировать его скорость, направление вращения и угол поворота по необходимости.

#### Аппаратное обеспечение

1\. Плата разработки UNO R3 (ch340) x1

2\. Шаговый двигатель 28BYJ-48 x1

3\. Плата управления шаговым двигателем ULN2003 x1

4\. Макетная плата x1

5\. Провода DuPont

#### Принцип работы

28BYJ-48 — это 5-проводной униполярный шаговый двигатель, работающий от 5В. Он идеально подходит для проектов, требующих точного позиционирования, например, для открытия и закрытия вентиляционного отверстия.

![IMG_256](../media/eaa9767eef79c07e0940bb0ffabf67b2.jpeg)

Поскольку двигатель не использует контактные щетки, он обеспечивает относительно точное движение и является достаточно надежным.

Несмотря на свои небольшие размеры, двигатель развивает приличный крутящий момент 34,3 мН·м при скорости около 15 об/мин. Он обеспечивает хороший крутящий момент даже в состоянии покоя и поддерживает его, пока двигатель получает питание.

Единственным недостатком является то, что двигатель потребляет достаточно много энергии и расходует ее даже в неподвижном состоянии.

#### Распиновка шагового двигателя

Шаговый двигатель 28BYJ-48 имеет пять проводов. Распиновка следующая:

![](../media/5afa64d2801a39482ca60d93dd4c9996.jpeg)

28BYJ-48 имеет две обмотки, каждая из которых имеет центральный отвод. Эти два центральных отвода соединены внутри и выведены как пятый провод (красный провод).

Вместе один конец обмотки и центральный отвод образуют **фазу**. Таким образом, у 28BYJ-48 всего четыре фазы.

Красный провод всегда подтянут к HIGH, поэтому когда другой вывод подтянут к LOW, фаза активируется.

Шаговый двигатель вращается только тогда, когда фазы активируются в логической последовательности, известной как **последовательность шагов**.

Плата драйвера ULN2003

Поскольку шаговый двигатель 28BYJ-48 потребляет значительное количество энергии, его нельзя управлять напрямую с помощью микроконтроллера, такого как Arduino. Для управления двигателем требуется драйверный ИС, например ULN2003; поэтому этот двигатель обычно поставляется с драйверной платой на базе ULN2003.

ULN2003, известный своей способностью работать с высоким током и высоким напряжением, обеспечивает больший коэффициент усиления тока, чем один транзистор, и позволяет низковольтному и низкотоковому выходу микроконтроллера управлять шаговым двигателем с высоким током.

ULN2003 состоит из массива из семи пар транзисторов Дарлингтона, каждая из которых может управлять нагрузкой до 500 мА и 50 В. Эта плата использует четыре из семи пар.

![](../media/8e052b728d6463257e8fa214f366c02d.png)

Плата имеет четыре управляющих входа и подключение питания.

Кроме того, имеется разъем Molex, совместимый с разъемом двигателя, что позволяет подключить двигатель напрямую.

На плате установлены четыре светодиода, которые показывают активность на четырех управляющих входах. Они обеспечивают хороший визуальный индикатор во время работы.

На плате есть джампер ВКЛ/ВЫКЛ для отключения шагового двигателя при необходимости.

#### Распиновка драйвера шагового двигателя

Плата драйвера ULN2003 имеет следующую распиновку:

![4ef410025565046bbc27ce9c339dfca8](../media/d235dd02952e87945f6e734228c386f2.jpeg)

IN1 – IN4 — входы управления двигателем. Подключите их к цифровым выходам Arduino.

GND — земля.

VCC — питание двигателя. Поскольку двигатель потребляет значительное количество энергии, предпочтительно использовать внешний источник питания 5В, а не питание от Arduino.

out1-out4 — сюда подключается двигатель. Разъем имеет ключ для правильного подключения.

#### Схема подключения

1. Подключите шаговый двигатель к выводам out1, out2, out3, out4 на плате драйвера ULN2003.

2. Подключите выводы + и - платы ULN2003 к 5V и GND на плате разработки соответственно.

3. Подключите цифровые выводы D8, D9, D10, D11 на плате разработки к выводам IN1, IN2, IN3, IN4 на плате драйвера.

#### Пример кода

```cpp

/*

Electronics Learning Starter Kit for Arduino

Project 21

Stepper Motor

Edit By Keyes

*/

#include <Stepper.h>

const int stepsPerRevolution = 2048; // the steps of a cycle

// initialization

Stepper myStepper(stepsPerRevolution, 8, 10, 9, 11);

void setup() {

// Set motor speed(rpm)

myStepper.setSpeed(5);

// initialize serial port

Serial.begin(9600);

}

void loop() {

// rotate a cycle clockwise

Serial.println("clockwise");

myStepper.step(stepsPerRevolution);

delay(500);

// rotate half a cycle counterclockwise

Serial.println("counterclockwise");

myStepper.step(-stepsPerRevolution / 2);

delay(500);

}
```

#### Объяснение кода

Импорт библиотеки

```cpp
#include <Stepper.h>
```

Эта строка кода импортирует библиотеку Stepper в Arduino, которая предоставляет функции и методы для управления шаговыми двигателями, упрощая программирование.

Определение констант и создание объекта Stepper

```cpp

const int stepsPerRevolution = 2048; // Количество шагов на один оборот

Stepper myStepper(stepsPerRevolution, 8, 10, 9, 11);

```

Здесь определяется константа `stepsPerRevolution`, представляющая количество шагов, необходимых двигателю для полного оборота. Это значение зависит от конкретной модели и конфигурации двигателя. Далее создается объект `myStepper` класса `Stepper`, инициализированный количеством шагов и четырьмя номерами выводов (8, 10, 9, 11), которые управляют двигателем. Эти четыре вывода подключены к управляющему интерфейсу драйвера шагового двигателя.

Функция setup

```cpp
void setup() {

myStepper.setSpeed(5); // Установка скорости двигателя (об/мин)

Serial.begin(9600); // Инициализация последовательного порта

}
```

В функции `setup()` сначала вызывается `myStepper.setSpeed(5);` для установки скорости вращения двигателя на 5 оборотов в минуту (об/мин). Затем инициализируется последовательный порт связи с помощью `Serial.begin(9600);`, устанавливая скорость передачи данных 9600 бод для передачи данных и вывода отладочной информации.

Основной цикл

```cpp
void loop() {

Serial.println("clockwise"); // Вывод информации о вращении по часовой стрелке

myStepper.step(stepsPerRevolution); // Вращение двигателя по часовой стрелке на один оборот

delay(500); // Задержка 500 миллисекунд

Serial.println("counterclockwise"); // Вывод информации о вращении против часовой стрелки

myStepper.step(-stepsPerRevolution / 2);// Вращение двигателя против часовой стрелки на пол-оборота

delay(500); // Задержка 500 миллисекунд

}
```

В функции `loop()` сначала выводится сообщение "clockwise" с помощью `Serial.println("clockwise");`, затем вызывается `myStepper.step(stepsPerRevolution);` для вращения двигателя по часовой стрелке на полный оборот. Функция `delay(500);` приостанавливает выполнение программы на 500 миллисекунд.

Далее выводится сообщение "counterclockwise" и вызывается `myStepper.step(-stepsPerRevolution / 2);` для вращения двигателя против часовой стрелки на пол-оборота. Отрицательное значение указывает направление вращения против часовой стрелки. После этого снова происходит задержка на 500 миллисекунд.

#### Результат проекта

После загрузки кода шаговый двигатель будет вращаться по часовой стрелке на один оборот, а затем против часовой стрелки на пол-оборота в цикле. При этом направление вращения можно отслеживать в режиме реального времени на мониторе.
